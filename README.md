# dz-catalog-analysis

Домашнее задание №1. Аналитика каталога стримингового сервиса 

## Запуск

```bash
uv sync
uv run catalog_analysis.py
```

## Проверка стиля

```bash
uv run ruff check .
```

## Структура

- `catalog_analysis.py` — единственный исполняемый файл с решением по 9 этапам
- `pyproject.toml` — конфигурация проекта (uv) и ruff
- `uv.lock` — зафиксированные версии зависимостей

## Этапы

1. Разминка: переменные, числа, `math`
2. Условия и `match`
3. Циклы
4. Строки
5. Списки
6. Словари
7. Множества
8. Итераторы и генераторы
9. Итоговый отчёт
